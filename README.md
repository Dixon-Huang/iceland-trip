# 冰岛行程 12/2–12/9（离线网页应用）

一个装到 iPhone 主屏幕、断网也能打开的行程应用：每天的时间表、示意地图、导航按钮、清单和开车须知。

## 装到手机

1. 用 **Safari** 打开 `https://dixon-huang.github.io/iceland-trip/`
2. 点底部的分享按钮 → **添加到主屏幕**
3. 从主屏幕图标打开一次，等几秒，到「须知」页最下面看到「离线缓存已就绪」
4. 开飞行模式再打开一次，确认能离线使用

三个人都可以各自这样装。清单的勾选只保存在各自手机上。

## 离线导航

App 里的「导航」按钮会打开 Google 地图或苹果地图。出发前在 Google 地图里下载离线地图（头像 → 离线地图 → 选择自己的地图），范围覆盖 KEF、雷克雅未克、黄金圈、南岸一直到 Hali，断网也能导航。

## 修改行程

只需要改 `data.js` 一个文件。

1. 在 GitHub 打开 `data.js`，点右上角铅笔图标
2. 修改后点 **Commit changes**
3. 约 1–2 分钟后网站更新；联网打开 App，重开一次即可看到

**改一项安排**：找到那一天的 `items`，每一行是一项：

```js
{ t: "10:30", w: "Seljalandsfoss", n: "备注，可省略", p: "seljalands" },
```

- `t` 时间，`w` 内容，`n` 备注（可删），`p` 地点代号（可删，有它才会出现导航按钮）
- 每行末尾的逗号不能少；引号用英文引号 `"`

**加一个新地点**：在最上面的 `places` 里加一行，再在 `items` 里用它的代号：

```js
newplace: { n: "显示的名字", q: "Google 地图里搜索用的名字", lat: 64.0, lon: -21.0, k: "sight" },
```

提交后，仓库的 Actions 页会自动检查格式。出现红叉说明有错，点进去能看到哪一天、哪一项写错了；这期间 App 继续显示上一个正确的版本。
